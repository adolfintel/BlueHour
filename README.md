# Blue Hour
This project aims to port vintage Nvidia Techdemos to modern platforms.

## Project status
Alpha. Runs about a dozen techdemos perfectly, only supports Linux for now.

## Download (prebuilt and with all demos preinstalled)
For Linux ([TDF](https://github.com/adolfintel/tdf)-based archive): [Download](https://downloads.fdossena.com/geth.php?r=dusk-bin)

Needs a modern Linux distro with Wine, Vulkan drivers and Zenity installed.
